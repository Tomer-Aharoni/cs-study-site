## 📌 הוראות הטמעה כלליות

כל מעבדה מוטמעת בתוך תוכן סעיף (`unitN.js` בתוך `html: \`...\``) באמצעות תגית `<div>` עם המחלקה `prob-lab` ומאפיין `data-prob-lab="KIND"`:

```html
<div class="prob-lab" data-prob-lab="KIND" data-param="value"></div>
```

- **ללא סגנונות מוטבעים (inline styles):** כל העיצוב, הצבעים ומצבי כהה/בהיר (Dark/Light) מוגדרים ב־`css/prob.css` באמצעות משתני CSS של האתר.
- **נגישות מלאה:** המעבדות כוללות מאפייני ARIA, ניווט מקלדת, תמיכה בקוראי מסך ועמידה בהגדרת `prefers-reduced-motion`.
- **הדרכה מובנית:** כל מעבדה כוללת שורת הסבר קצרה בעברית מדוברת («מה לנסות כאן») המכוונת את הסטודנט לפעולות המרכזיות.

### 2. `stars` — כוכבים ומחיצות

### 3. `pascal` — משולש פסקל וזהויות מקדמים
- **יחידה וסעיף מומלצים:** יחידה 1 (קומבינטוריקה) · `p1-binomial` / `p1-pascal`
- **תיאור:** משולש פסקל אינטראקטיבי המציג מקדמים בינומיים $\binom{n}{k}$. לחיצה על משבצת מדגישה את שני ההורים לפי זהות פסקל $\binom{n}{k} = \binom{n-1}{k-1} + \binom{n-1}{k}$, מציגה סכומי שורות $2^n$ ומאפשרת צביעת פרקטל שרפינסקי לפי זוגיות.

|--------|-------|------------|------------|------|
| `data-rows` | מספר שלם | `7` | `4` עד `11` | מספר שורות המשולש $N$ |
