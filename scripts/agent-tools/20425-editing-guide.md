# מדריך עריכה – קורס 20425 (הסתברות ומבוא לסטטיסטיקה)

מיועד לכל סוכן שעורך תוכן של 20425. קרא את כולו לפני שאתה נוגע בקובץ.

## מטרה
סטודנט עם רקע מתמטי מינימלי צריך להבין את החומר מהאתר לבדו. העריכה משפרת הסבר, ניסוח, דוגמאות והמחשות, ואינה משנה את הסילבוס.

## רמות הרחבה (סימון להמשך עבודה)
כל קובץ שנערך מקבל בשורה הראשונה הערה:

`// edit-pass: 1 | expansion: L1 | date: YYYY-MM-DD`

- **L0** – תוכן מקורי של Cursor, לא נערך.
- **L1** – עריכה לשונית והרחבה של כ-30% באורך ובדוגמאות (השלב הנוכחי).
- **L2** – הרחבה נוספת (שמורה להמשך, ייתכן שלא יבוצע). לכן ב-L1 שמור «נקודות הרחבה» (ראה למטה).

**נקודות הרחבה:** בסוף כל סעיף שכדאי להרחיב עוד, הוסף הערת HTML/JS: `<!-- L2: מה אפשר להוסיף כאן, במשפט אחד -->` (בתוך ה-html של הסעיף). המסמך `20425-progress.md` הוא המקום המרכזי למעקב.

## תקרת גודל (מחייב)
L1 = כ-30% הרחבה. בפיילוט של יחידה 1 הסוכן חרג (+166% בטקסט). מעכשיו: טקסט היחידה לא יעלה על **+60%** מגודל ה-L0 (בייטים), ו-2 דוגמאות פתורות לסעיף כברירת מחדל (3 רק בסעיפים מרכזיים). חומר שחורג מהתקרה עובר להערת `<!-- L2: ... -->`. דווח בדוח את הגודל לפני/אחרי.

## מבנה סעיף
1. פתיחה: שאלה או מצב מהחיים/ממדעי המחשב שמסביר *למה* צריך את הכלי.
2. אינטואיציה במילים פשוטות.
3. הגדרה/נוסחה (רשימת מונחים `term-list` כמו היום).
4. «דוגמה פתורה» שלב אחר שלב. 2–3 דוגמאות בסעיפים מרכזיים: קלה, בינונית, בסגנון מבחן.
5. «מוקש נפוץ» (`panel`) כשיש.
6. מעבדה (`<div class="prob-lab" ...>`) או הפניה למעבדה כשיש מתאימה.

## שפה
- עברית מדוברת, משפטים קצרים. בלי ניסוח אקדמי כבד, בלי «כלומר» בכל משפט.
- כל סמל מוסבר בהופעה הראשונה. מונח באנגלית בסוגריים בהופעה ראשונה בלבד.
- אינטגרל, סכום או הוכחה: קודם הסבר מילולי ודוגמה מספרית, אחר כך הפורמליזם.
- אל תשתמש בקישוטים («בואו נצלול», אימוג'ים, התלהבות מוגזמת).

## נאמנות
- כל נוסחה, הגדרה וערך מספרי מוצלבים עם `sources/20425/text`. אין חומר מעבר לסילבוס.
- כל מספר חדש מחושב ומאומת בסקריפט Python לפני הכתיבה (שמור סקריפטים זמניים מחוץ לריפו).
- אל תמציא פרטי מבחנים. הפנה למועד רק אם הוא ב-`sources`.

## טכני
- שמור את מבנה הקובץ, את מזהי הסעיפים (`p1-counting`) ואת המפתחות. שינוי מזהה/הוספת סעיף חייב עדכון `data/20425/unit-parts.js` ובדיקה ב-`check-20425.js`.
- UTF-8 בלי BOM. LaTeX בתוך template literal נכתב `\\(...\\)` כמו בקבצים הקיימים. בלי backticks בתוך הטקסט.
- אל תיגע ב-`js/app.js`. מעבדות חדשות רק דרך `js/prob-labs.js` / `css/prob.css` (שלב נפרד, סוכן יחיד).
- אחרי כל קובץ: `node scripts/agent-tools/check-20425.js` ותיקון כל שגיאה.
- תחביר PowerShell: קרא קבצים עם `-Encoding UTF8`, ו-`[Console]::OutputEncoding=[Text.Encoding]::UTF8`.

### דגשים לכתיבת תרגילי הבית
1. **מקורות:** בחר 6–8 תרגילים מתוך `sources/20425/text/` של היחידה (`פרק N - תרגילים.md` ו־`פרק N - פתרונות.md`). דרג אותם מקל, דרך בינוני, ועד לרמת מבחן, כך שיכסו את כל סעיפי היחידה.
2. **עצמאות פדגוגית:** אל תעתיק פתרון רשמי מילה במילה. נסח מחדש שלב-אחר-שלב בשפה מדוברת ובהירה, הסבר "למה" בכל מעבר, והוסף מוקש נפוץ ו־"בדקו את עצמכם" לכל תרגיל.
3. **אימות מספרים:** אמת כל ערך מספרי, תוצאת ביניים ו־"בדקו את עצמכם" בסקריפט Python חיצוני מחוץ לריפו לפני הכתיבה.
4. **תחביר ו־LaTeX:** בתוך template literal נכתב `\\(...\\)` ו־`\\[...\\]`. אין להשתמש ב־backticks בגוף הטקסט.
5. **בדיקה:** הרץ `node scripts/agent-tools/check-20425.js <katex-path>` לוודא 0 בעיות (הבודק מזהה וטוען את `unitN-hw.js` אוטומטית).
