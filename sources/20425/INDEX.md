# מקורות 20425 · הסתברות לתלמידי מדעי המחשב

הקבצים עצמם לא בגיט. רק המפה הזו בגיט. כדי לשחזר מתיקיית ההורדות:

```
python scripts/agent-tools/ingest-20425-sources.py "<תיקיית המקור>"
python scripts/agent-tools/ocr-20425-sources.py
```

הסקריפט הראשון מעתיק ל־`raw/` ומחלץ טקסט ל־`text/` (אותו נתיב, סיומת `.md`, כותרת לכל עמוד). השני מריץ OCR בעברית ובאנגלית על קבצים סרוקים. הוא משתמש ב־`_tessdata/` (heb מ־tessdata_best). `_report.json` מפרט עמודים ותווים לכל קובץ.

בקבצים שעברו OCR (מסומנים «(OCR)» בשורה הראשונה) העברית סבירה והנוסחאות משובשות. לכן הם מתאימים לבדיקת מונחים והיקף, לא להעתקת נוסחה.
