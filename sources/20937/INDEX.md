# מקורות 20937 · תכנות מערכות דפנסיבי

הקבצים עצמם לא בגיט, חוץ מהערות NotebookLLM ב־`notes/notebookllm/`. המפה הזו כן.

שמות הקבצים ב־`raw/` נקבעו לפי העמוד הראשון. בפריסה המקורית העברית בשם הקובץ נמחקה ונשארו רווחים.

## מקור (`raw/`)

הקבצים הבינאריים שהיו ב־`temp_unzip`.

| תיקייה | מה יש בה |
|--------|----------|
| `units/` | יחידה 1 (מבוא), יחידה 2 (שפת C++, 2025), יחידה 5 (תקשורת) |
| `slides/` | מצגות יחידות 3, 4, 5–6 (יובל), 7 (בסיסי נתונים וקוד נקי) |
| `exams/` | שאלונים, פתרונות ושחזורים: 2021א קיץ, מבחן לדוגמא, 2024א (שאלון 92 ופתרון 10.3), 2024ג (שאלון 61), שחזור 2025ג מועד ג, שאלון משוחזר 2025ג 81, שחזור 2026, שאלות אמריקאיות |
| `exams/_עותק-זהה/` | עותק זהה של קובץ השאלות האמריקאיות |
| `practice/` | שאלות הכנה למבחן |
| `course-page/` | עמוד הקורס שנשמר מהאו״פ |
| `archive/` | `חבילה.rar`, בלי פירוק |

ב־`יחידה 5 - תקשורת.pdf` כותרת ה־PDF היא «חשבון דיפרנציאלי». הטקסט בעמוד הראשון הוא יחידה 5, תקשורת. ב־`שחזור 2026.pdf` כותרת ה־PDF שייכת לשאלון 2025ג 81, ומפתח התשובות שונה. השם נשאר לפי שם הקובץ המקורי.

## הערות (`notes/`)

- `notebookllm/` — תוספות לפי יחידה, וה־PDF «שאלות לדפנסיבי». זה החלק שנשמר בגיט.
- `guide.md` — מדריך מקוצר למבחן. לא בגיט.
- `working/` — תוצרי ביניים (`all_code.txt`, `tips.txt`, `current_notes.txt`). לא בגיט.

סקריפטי עיבוד חד־פעמיים שהיו בשורש הפרויקט עברו אל `scripts/archive/`.
